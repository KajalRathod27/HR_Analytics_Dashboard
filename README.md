# 🚀 HR Analytics Dashboard

## 📌 Overview
This project is an end-to-end HR Analytics Dashboard designed to analyze employee attrition, salary trends, and workforce insights.

It combines **interactive web analytics (Streamlit)** with **business intelligence (Power BI)** to deliver actionable insights.

## 📊 Features

### 📌 Overview Dashboard
- Total Employees, Attrition Rate, Avg Salary
- Employee distribution by age, salary, overtime

### 📉 Attrition Analysis
- Attrition by Job Role, Department, Tenure
- Overtime vs Attrition insights

### 💰 Salary Analysis
- Salary band distribution
- Salary vs Attrition relationship
- Salary gap analysis

### 🔮 ROI Simulator
- Predict impact of salary increase on attrition
- Estimate employee retention
- Calculate ROI for HR decisions
